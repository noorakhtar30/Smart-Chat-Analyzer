# 📊 Smart Chat Analyzer

Smart Chat Analyzer is a WhatsApp chat analytics platform built using Python and Streamlit. It converts exported WhatsApp conversations into interactive dashboards, visual reports, and meaningful insights through data analysis and natural language processing techniques.

## 🚀 Features

- Message, word, media, and link statistics
- Monthly and daily chat timelines
- User activity analysis
- Most active users detection
- Weekly activity heatmaps
- Word cloud generation
- Most frequently used words analysis
- Emoji usage analytics
- Message length distribution
- Sentiment analysis using NLP
- Conversation starter detection
- Response time analysis
- Inactive user tracking
- Interactive rule-based chat assistant
- PDF report generation

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn
- TextBlob
- WordCloud
- URLExtract

## 📈 Key Insights Generated

- Communication patterns
- User engagement trends
- Peak activity periods
- Sentiment distribution
- Conversation dynamics
- Emoji behavior analysis
- Response behavior tracking

## ⚙️ Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📖 Usage

1. Export a WhatsApp chat without media.
2. Upload the exported `.txt` file.
3. Select a specific user or analyze the complete chat.
4. Explore interactive visualizations and insights.
5. Generate and download PDF reports.

## 🔒 Privacy

All chat processing is performed locally. No chat data is stored or transmitted to external servers.
